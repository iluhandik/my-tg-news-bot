# 🤖 Автоматизована система новин та генерації Reels/Shorts для Telegram і соцмереж

Цей додаток автоматизує повний цикл роботи сучасного новинного медіа:
1. **Моніторинг та парсинг джерел** (RSS-стрічки провідних новинних агентств).
2. **AI-рерайтинг та фільтрація** (очищення від згадок першоджерел, структурування, форматування для Telegram).
3. **Автопостинг у Telegram-канал** (текст + зображення).
4. **Автоматична генерація вертикальних відео (9:16)** для "мега-новин":
   - Створення вірусного дикторського тексту.
   - Озвучка українським нейромережевим голосом (Edge-TTS).
   - Монтаж відео 1080x1920 (розмитий фон, фото події, плашка "ТЕРМІНОВА НОВИНА", субтитри та брендинг каналу).
5. **Дистрибуція відео** у популярні соцмережі (TikTok, YouTube Shorts, Instagram Reels, Facebook Reels, Threads).

## 📂 Структура проєкту

```

```

## 🚀 Швидкий старт (Локально)

### 1. Системні вимоги
- **Python 3.10+**
- **FFmpeg** (обов'язково для генерації відео):
  - *Ubuntu/Debian:* `sudo apt install ffmpeg fonts-noto-core`
  - *macOS:* `brew install ffmpeg`
  - *Windows:* завантажити з ffmpeg.org або встановити через `winget install Gyan.FFmpeg`

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Налаштування змінних оточення
Створіть файл `.env` на основі `.env.example`:
```bash
cp .env.example .env
```
Заповніть ваші ключі:
- `TELEGRAM_BOT_TOKEN`: Отримайте у [@BotFather](https://t.me/BotFather).
- `TELEGRAM_CHANNEL_ID`: Юзернейм вашого каналу (наприклад, `@my_channel`) або числовий ID. **Обов'язково додайте створеного бота в адміністратори каналу з правом публікувати повідомлення!**
- `CHANNEL_USERNAME`: Посилання на ваш канал для банерів у відео (наприклад, `@my_channel`).
- `AI_API_KEY`: Ключ OpenAI (`sk-...`) або Groq / Gemini.

### 4. Тестовий запуск
Перевірте роботу системи в тестовому режимі (1 цикл):
```bash
python main.py --once
```

Для постійної фонової роботи:
```bash
python main.py
```

## 🐳 Запуск на сервері (Docker)

Найпростіший спосіб розгорнути систему на VPS:
```bash
docker compose up -d --build
```
Бот працюватиме 24/7 у фоновому режимі, автоматично перевірятиме новини кожні 5 хвилин і самостійно перезапускатиметься при збоях.

## 📱 Автопостинг у соцмережі (TikTok, Shorts, Reels, Threads)

### Реалії публікації:
- **Офіційні API соцмереж (Meta Graph API, TikTok API):** вимагають створення бізнес-додатків та тривалої модерації (1–3 тижні).
- **Рекомендоване швидке рішення:**
  1. **Ayrshare API** (підтримується у `social_poster.py`): один API-запит автоматично завантажує відео у TikTok, YouTube Shorts, Instagram Reels, Facebook Reels та Threads.
  2. **Telegram Admin Bot (вбудовано):** бот надсилає згенероване відео адміну в приватні повідомлення з готовим описом, хештегами та посиланням на канал, що дозволяє викласти ролик у будь-яку мережу за 15 секунд без ризику блокування або тіньових банів.
